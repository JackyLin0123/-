# 训练故障诊断台

任务：识别三个互相隔离的错误，给出根因、修复和验证证据。

## 最小任务

1. 预测叶子 w=2、损失 (3w)² 连续两次新前向反传后的梯度，中间不清零。
2. 检查预测 (3,1) 与标签 (3,) 相减时的真实输出形状。
3. 审核训练索引 [0,1,2] 与验证索引 [2,3]，设计无重叠划分。

先写预测，再执行 `python run.py --out results`。参考实现含三种故障和修复对照，不涉及联网数据。

## 基线与验收

独立手算基线：一次梯度 36，累积两次为 72；错误广播均方误差 4/3，正确配对为 0；泄漏索引是 2。修复后分别为 36、0、空交集。全部断言必须通过，并能解释每一步。

## 产物

`results/results.json` 保留故障、修复前后观测和解释。为每项写一句根因，标出你修改的代码。

## 渐进提示

新 forward 不清空叶子梯度；广播从末轴对齐；验证独立性应检查样本身份，不只检查数组对象是否不同。

## 扩展

为每类 bug 编写失败测试，再把测试放进实际训练程序。添加“忘记 step”和“eval 没有禁用梯度”案例，分别记录验证方式。

## 失败与边界

修复一个错误不保证整个模型正确；合成样本身份检查不能替代分组/时间泄漏审查。这里不是算法性能基准。
