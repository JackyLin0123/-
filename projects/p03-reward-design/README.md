# 奖励规则设计挑战

原创教学项目。任务成功是到达 3×3 网格右下角，不以训练奖励代替成功率。

## 最小任务

固定种子 1、7、17，分别比较正常奖励与原地停留奖励。五个动作是右、下、左、上、停留；越界不移动。到终点奖励10并自然终止，其他步骤奖励−1。对照条件额外将停留动作奖励改为2。

先预测行为，再运行 `python run.py --out results`。仅需 Python 标准库，不依赖 GPU 或外部数据。

## 协议与基线

Q-learning：γ=0.9、α=0.2、ε=0.2，每组400回合。采集最多100步；只有到目标才自然终止，采集截断继续按非终止转移构造自举目标。评估采用贪心策略，最多30步。只改变奖励规则，其余预算一致。

基线是任务一致奖励。比较每个种子的到达目标与否、评估奖励、步数及轨迹。先确认环境边界测试、终止与奖励规则正确；不要求所有随机种子必须支持原假设。

## 可检验假设

停留奖励可能让策略获得更高奖励却不完成任务。γ=0.9 时无限停留的折扣回报为20，超过立即到终点的10。这是该设计的动机，不是任何环境中都存在同样捷径的论断。

## 产物与验收

`results/results.json` 包含协议、各回合记录、Q表、评估轨迹及环境。检查边界、终止、有限数值断言；分析训练奖励与实际成功为何可能相反。截图不能代替结果文件。

## 渐进提示

1. 先手写状态0的全部转移。
2. 区分自然终止与100步采集上限。
3. 分别报告成功与奖励，不能只选有利种子。

## 扩展

修改停留奖励为0.1、0.5或1，寻找策略切换；改变折扣比较预测；添加随机转移并重新分析。不要同时改变多个条件。

## 常见失败

把超时一律当自然终止；以训练回合奖励作为目标成功率；泄漏最优动作给策略；只保存最好的种子。
