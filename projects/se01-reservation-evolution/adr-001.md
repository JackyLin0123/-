# ADR-001：服务私有 Store 端口

状态：本项目教学选择；不是工业通用最优方案。

背景：需要演示可替换存储，保证相同契约。候选 A：Book 直接持 ArrayList；候选 B：私有 Store 接口加 ListStore/TreeStore。选择 B，仅装配选择具体实现，CLI 与冲突规则不需要改。

质量场景：在 JDK17 单线程和固定 fixture 下，把 list 装配改 tree；业务规则零改动，四套原版/重构与两存储契约都通过。实际证据是 run.log；调用关系 CLI→Book→具体 Store，静态依赖 Book→Store，适配器实现 Store。

代价：增加类与端口约束，复制快照 O(n)，冲突逐项扫描 O(n)；教学 checkRep 还加 O(n²) 校验。树按 ID 删除改善其定位能力，但不提供时间区间索引，不承诺性能提升。只有实测出现区间查询瓶颈或引入持久化故障模型时重审；单一小脚本可选择 A。
