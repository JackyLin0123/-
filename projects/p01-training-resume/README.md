# 从数据到恢复：训练一个小模型

任务：用合成数据学习 y≈2x+1。先独立实现，再对照参考实现。

## 最小任务

1. 固定种子和样本身份，拆出训练、验证、测试集合；只用训练集拟合标准化。
2. 打印预测、损失、梯度与更新后的权重，完成带动量 SGD 循环。
3. 根据验证损失选择模型；保存权重、优化器、步数与随机状态。
4. 中断后恢复，再与不中断的 35 步训练比较；最后对选中的模型做测试评估。

## 运行与产物

在本目录执行 `python run.py --out results --seed 17`。输入由脚本生成，无需下载数据。产物是 `results/results.json` 与 `results/checkpoint.pt`。结果中保留划分、标准化参数、每轮指标、环境和源码摘要。

## 基线与验收

基线恒预测训练标签均值。检查集间身份不相交、训练损失下降、加载预测一致，以及同环境同批次恢复后参数逐位一致。测试指标只用于最终报告，不用于选择训练轮次。这个合成任务的结果不能外推到真实数据。

## 渐进提示

先只训练一个权重，再增加偏置；先固定 batch 顺序。若恢复不一致，检查 optimizer.state_dict，尤其动量缓冲区。内存中保留最佳状态时用深拷贝。

## 扩展

添加随机 mini-batch，保存生成器及采样位置；比较不同训练种子。加入 Dropout 后再次检查随机状态恢复。扩展完成需要新的实验记录。

## 常见失败

全数据标准化造成泄漏；把 state_dict 的引用当作冻结快照；漏存动量；用最后一次模型替代验证选中的模型。
