# ALG01：设计、证明与独立核对

这是本站原创 Java 基础语法项目。先写自己的算法、证明和失败例子，再读参考代码。只依赖 JDK 17+ 与 Python 3.11+ 标准库，无下载数据、无服务器依赖。实测工具版本和实际命令保存于 results.json；项目自评不能自动认证任何节点掌握。

在仓库根目录运行：

```powershell
python -B -X utf8 projects/alg01-design-proof/run.py --out _build/verify/se-alg-arch/ds-project
```

run.py 将三个 Java 文件复制到新的系统临时目录，在那里 `javac -encoding UTF-8 -d <classes> ...`，再执行 `java -cp <classes> LabTest`。编译与运行分别用 30 秒 subprocess 超时，退出时清理临时类文件；不会向源码目录写 .class。用 `--out` 选择独立结果目录，输出 results.json 与 stdout/stderr 日志。超时或缺 JDK 会保存失败/跳过原因，不能登记通过。

最小作业：

1. 逆序对：在 [3,1,2] 上先列两对逆序，再解释归并时何时一次加多对。补重复值与空数组。
2. 活动选择：证明无权最早结束贪心。对 `[0,2):2,[2,4):2,[0,4):5` 解释 4 与 5，完成加权前缀 DP。
3. 背包：二维表、方案恢复、错误正序对照；W=4/w=[2,3,4]/v=[4,5,7] 的正确值 7，错误值 8。迁移 W=5 应得 9。
4. LCS：ABCD/ACBD 长度 3，检查子序列顺序；不得仅对比 ABD 某个唯一字符串。迁移 AB/BA 与空串。
5. 流/归约：保存三次增广 trace 和容量 3 的割；写二分匹配的双向转换。完成独立集/覆盖互补证明及四点路径的二近似紧例。

`PROOFS.md` 是可审阅的完整证明与复杂度说明。`BruteOracle.java` 使用双循环、子集/子序列/匹配/割枚举，独立于优化实现。`LabTest.java` 穷举：长度 0..7、值 {-1,0,1} 的数组；最多 3 件、重量 1..3、价值 0..3、容量 0..7 的背包；长度 0..4 的二字母串对；所有四点有向无环限制以外的 0/1 有向图（包括反向边）；所有 3×3 二分图；所有四点简单无向图；固定区间集合及小权重。准确数量和断言数由程序实际输出。

独立核对的通过只说明这些有限输入未发现差异。普遍正确性依赖证明；证明也不覆盖 Java 溢出、任意超大内存分配或外部恶意输入。本项目输入由固定 fixture 和有界枚举产生。LCS 按 ASCII 字符解释，不处理 Unicode 字素簇。流实现为残量矩阵，复杂度见证明，不冒充邻接表实现。

扩展需要用户自己完成并记录：把背包容量改成 5；把 LCS 换为 ABA/BAB；给加权区间生成新的反例；把流容量改成 2 并枚举割复核。每次写预测、唯一改变量、实际输出、证明哪步仍成立及一个未覆盖边界，再在网站自评。参考实现运行成功不等于已独立完成扩展。
