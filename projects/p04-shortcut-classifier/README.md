# 会走捷径的分类器

## 问题与假设
模型在训练分布中表现很好，是否学到了预期的形状？控制测试背景与标签的关联，检查性能变化。假设是关联改变可能暴露捷径；必须报告全部种子，即使没有出现预期下降。

## 数据、基线与预算
脚本独立生成8×8横条/竖条图，标签0为竖条、1为横条。形状幅度0.8、噪声标准差0.12，背景±0.65与标签关联。训练256、验证128、测试256；分组使用不同生成种子。每个测试条件共享相同标签、形状与噪声，只改变背景为相关、反转或中性。训练80步，SGD学习率0.08，验证损失选模型；三种子1/7/17。基线为同一模型在相关背景上的准确率。测试不选超参数。

## 论文支持与原创边界
Geirhos等《Shortcut Learning in Deep Neural Networks》§3与图2说明星/月示例中的位置混淆；§6.2讨论分布外测试对识别捷径的作用。本项目采用问题视角，合成条纹和背景干预为原创任务，不是原论文实验复现，不引用论文的数值作为本项目结果。

## 最小产物与验收
保存三种子的训练/验证曲线、三条件准确率、配对预测。保持基准样本一致，解释中性与反转条件为何检验不同问题。运行断言仅检查协议与数值合法，不强制假设成立。

## 渐进提示与扩展
先画出一组配对样本；检查生成种子与标签；打印背景均值；再比较预测。扩展只改训练背景相关强度，保留原测试集与预算；或先去均值再训练，但不要同时改模型。常见错误：测试调参、只报最好种子、把性能差异当作特征的因果解释。

## 环境与运行

CPU、Python 3.11、PyTorch 2.9.1+cpu已验证，单线程。进入本项目目录执行 `python run.py --out results`。可在独立虚拟环境安装 `requirements-verified.txt`；普通 requirements 为兼容范围，其他版本须重验。无外部数据和平台账户。

本机运行段耗时 5.34 秒（不含 Python/PyTorch 导入与安装）；峰值进程工作集约 250.9 MiB，含框架运行时。系统负载会改变时间，不承诺其他机器相同。

产物为 `results/results.json`。参考实跑记录在仓库 `_build/verify/p04-shortcut-classifier/`；源码及结果保留摘要。
