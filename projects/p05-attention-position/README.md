# 小型序列任务的注意力对照

## 问题与可检验假设
三个独立U[-1,1]数值组成序列，分类目标是第0个数的正负。任务依赖位置；没有位置的对称注意力池化不能区分置换。加入位置后可能改善该任务，但不预设任何一次实验必须成功。

## 公平对照协议
固定训练512、验证128、测试256，生成种子按split隔离。三种子1/7/17。唯一消融变量是key的固定三维one-hot位置特征或全零位置特征；其余输入、初始六个参数、优化器Adam lr=0.05、180步预算完全一致。没有位置的版本仍保留相同数量的参数槽。基线为无位置池化，程序验证其置换不变性。

## 模型与信息边界
一个四维可学习查询与[value,position]点积除以sqrt(4)，softmax后加权原始数值，再用标量线性头分类。不是完整Transformer。这是已观察完整序列的分类任务，不是因果生成任务；不需要遮住后续输入。不要把本任务的完整观察设置移植到预测未来标签。

## 产物与验收
按验证损失选checkpoint，测试仅最终评估。保存所有训练曲线、参数量、准确率及错误输入；比较同一seed的两条件，不只挑正面结果。解释无位置时的排列对称性与位置表示怎样打破对称性。

## 渐进提示与扩展
先手算两种排列是否给出相同目标；再检查无位置模型输出；最后加位置。扩展把目标改为第2个位置，或者单独比较固定和可学习位置。每次只改变一个变量。常见错误是增加位置时同时增大参数或训练预算。

## 环境与运行

CPU、Python 3.11、PyTorch 2.9.1+cpu已验证，单线程。进入本项目目录执行 `python run.py --out results`。可在独立虚拟环境安装 `requirements-verified.txt`；普通 requirements 为兼容范围，其他版本须重验。无外部数据和平台账户。

本机运行段耗时 6.41 秒（不含 Python/PyTorch 导入与安装）；峰值进程工作集约 252.5 MiB，含框架运行时。系统负载会改变时间，不承诺其他机器相同。

产物为 `results/results.json`。参考实跑记录在仓库 `_build/verify/p05-attention-position/`；源码及结果保留摘要。
